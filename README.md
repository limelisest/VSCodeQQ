# VSCode QQ · 原生代码风格 QQ 客户端

在 VS Code 原生编辑器里畅聊 QQ。基于 **OneBot v11** 协议规范，推荐配合 **[SnowLuma](https://github.com/SnowLuma/SnowLuma)** 使用，同时广泛兼容 **NapCat**、**Lagrange**、**LLOneBot**、**OpenShamrock** 等各类主流 OneBot 服务端。

聊天记录以 C / Python / TypeScript 等代码语法风格高亮呈现，底部直接编写发送草稿，完美融入开发者的工作流与代码编辑习惯。

![0.2.8 原生聊天：代码风格聊天、回复与@高亮、防撤回标红及草稿占位符](docs/images/message-highlights.png)

## ✨ 核心特性

- **💻 原生编辑器体验**：直接在编辑器底部草稿区输入，`Enter` 发送，`Shift+Enter` 或 `Ctrl+Enter` 换行；完美沿用 VS Code 的字体、主题配色、行号与快捷键。
- **🔌 广泛兼容 OneBot v11**：支持所有标准的 OneBot v11 正向 WebSocket 服务（首推 SnowLuma，亦支持 NapCatQQ、Lagrange.Core、LLOneBot 等）。
- **🎨 多语言代码高亮**：支持 C（默认）、Python、JavaScript、TypeScript、Dart、Kotlin、Java、Swift 等多种语法风格，随心切换。
- **🛡️ 本地防撤回**：当他人撤回消息时，本地已收到的文本与图片完整保留，消息尾部标注 `// 已撤回` 并以醒目红底标亮。
- **💬 智能回复与 @ 成员**：
  - 单击消息中的 `msg` 变量或快捷键 `Ctrl+Shift+R` 快速回复；删除草稿中的 `[回复:...]` 占位符即可取消回复。
  - 输入 `@` 智能补全群成员，或直接单击历史消息中的 `name` 变量快速提及。
- **🖼️ 丰富的多媒体收发**：
  - 聊天图片默认占位显示，鼠标悬停即享缩略预览，支持点击查看大图及一键引用到草稿。
  - 截图直接 `Ctrl+V` 粘贴、拖放本地图片/视频自动生成占位符，支持跨会话复制粘贴复用资源。
  - 输入 `!` 或 `！` 快速呼出表情面板（收藏表情、最近使用、QQ 原生表情）。
- **📁 丝滑的文件传输**：拖拽或使用 `/file` 插入附件，发送时实时显示上传进度与速度；点击收到的文件链接即可一键另存到本地。
- **⚙️ 现代卡片式设置面板**：重新设计的直观卡片式设置页面，提供动态色彩预览、连接测试状态徽标、消息通知范围及附件缓存一键清理。
- **⚡ 强大清爽的斜杠指令 (`/`)**：输入 `/` 即享分类清晰的指令补全列表，无多余冗余信息，涵盖消息操作、群文件、群管理及系统状态查询。

## 🚀 快速开始

### 1. 准备 OneBot v11 服务端

本插件基于标准 OneBot v11 协议通信。只要部署了任意支持 **正向 WebSocket** 的 OneBot 服务即可配合使用，常见实现推荐：

- **[SnowLuma](https://github.com/SnowLuma/SnowLuma)**（推荐）：现代化的 QQ 互操作运行时与 OneBot v11 框架，提供稳定优雅的 WebSocket 服务接入。在配置中启用 **正向 WebSocket 服务端**，消息上报格式建议选择 `array`。
- **[NapCatQQ](https://github.com/NapNeko/NapCatQQ)**：基于 NTQQ 的现代化框架。在 NapCat WebUI 的**网络配置**中新建 **WebSocket 服务端（正向 WS）**，消息上报格式选择 `array`，端口默认 `3001`。
- **[Lagrange.Core](https://github.com/LagrangeDev/Lagrange.Core)**：轻量纯净的 C# 实现。在配置中开启正向 WebSocket 服务，端口和 Token 按需设定。
- **[LLOneBot](https://github.com/LLOneBot/LLOneBot)** / **OpenShamrock**：同样在设置中启用正向 WebSocket 服务端即可。

> [!TIP]
> 建议将消息上报格式配置为 **`array`（消息段数组）**，以便插件完整解析图片、回复和 @ 提及。

### 2. 安装插件

1. 从 [GitHub Releases](https://github.com/limelisest/VSCodeQQ/releases/latest) 下载最新的 `.vsix` 安装包。
2. 在 VS Code 中打开扩展视图（`Ctrl+Shift+X`），点击右上角 `…` → **从 VSIX 安装…（Install from VSIX…）**。
3. 安装完成后，按 `Ctrl+Shift+P` 运行 **Developer: Reload Window（开发人员: 重新加载窗口）**。

### 3. 连接与配置

1. 点击 VS Code 左侧活动栏的 **QQ 消息图标**。
2. 在下方设置区点击 **连接设置**（或按 `Ctrl+Shift+P` 运行 `QQ: 连接设置`）。
3. 填入你的 OneBot WebSocket 地址（如 `ws://127.0.0.1:3001`）和 Access Token（若有）。
4. 点击 **测试连接**，验证成功后点击 **保存并连接**。
5. 当状态栏显示 `QQ · 已连接` 时，即可在左侧选择好友或群聊开始聊天！

## 📖 使用教程

### 常用操作一览

| 操作 | 快捷方式 / 操作方法 |
| --- | --- |
| **发送消息** | 在底部草稿区输入后按 `Enter` |
| **换行** | `Shift+Enter` 或 `Ctrl+Enter`（macOS 为 `Cmd+Enter`） |
| **回复消息** | 单击消息代码中的 `msg` 变量、右键菜单或 `Ctrl+Shift+R` |
| **取消回复** | 删除草稿里的 `[回复:群名片]`，或输入 `/cancel_reply` |
| **@ 群成员** | 输入 `@` 触发补全列表选择，或单击消息中的 `name` 变量 |
| **插入表情** | 输入 `!` 或 `！` 选择表情补全，或使用 `/emoji` |
| **发送图片** | 截图后直接 `Ctrl+V` 粘贴，或拖放图片文件，或使用 `/image` |
| **发送视频** | 拖入视频文件或使用 `/video`（支持 MP4、MOV、WebM 等格式） |
| **发送文件** | 按住 `Shift` 拖入文件，或使用 `/file` 命令选择文件 |
| **查看撤回** | 撤回消息保留原文并高亮标红，显示 `// 已撤回` 提示 |
| **跳转到底部** | 点击聊天窗口右上角向下箭头，或点击状态栏新消息提示 |
| **加载更早历史** | 点击右上角历史时钟图标，或执行 `QQ: 加载更多记录` |

### 斜杠指令 (`/`)

在底部草稿区输入 `/` 即可触发指令列表。所有指令均采用易读的英文命名，并带有清晰的中文说明与分类标签，操作直观友好：

- **快捷入口**：`/emoji`（表情面板）、`/image`（插入图片）、`/file`（发送文件）、`/mention`（提及成员）
- **消息互动**：`/reply`（回复）、`/recall`（撤回）、`/forward`（单条转发）、`/merge_forward`（合并转发）、`/poke`（戳一戳）、`/like`（点赞）
- **状态与资料查询**：`/status`（查看服务状态）、`/login`（登录账号）、`/user`（用户资料）、`/group`（群信息）、`/members`（成员列表）
- **群管功能**（仅群聊生效）：`/notices`（群公告）、`/ban`（禁言）、`/kick`（移出群）、`/card`（修改名片）、`/title`（专属头衔）
- **全局帮助**：`/help` 呼出指令搜索面板，输入关键词快速检索所有可用功能。

> [!NOTE]
> 如果整段草稿只包含一条指令（如 `/status`），直接按 `Enter` 即可执行该指令，不会作为文字发送到 QQ。

### 多语言代码风格

聊天记录支持自定义代码语法外观。在设置页面中切换“代码语言风格”，支持：
- **C**（默认）：经典的结构体与函数风格
- **Python**：简洁优雅的缩进函数风格
- **JavaScript / TypeScript**：现代前端风格
- **Dart / Kotlin / Java / Swift**：满足各类移动端与后端开发者的视觉偏好

### 转发与合并转发

- **单条消息转发**：在消息上右键选择 **QQ: 转发这条消息**，选择目标好友或群聊后即可直接发送。
- **多条合并转发**：右键选择 **QQ: 选择消息合并转发**（或执行 `/merge_forward`），勾选需要转发的多条记录，确认后合并发出。
- **查看合并转发**：点击聊天记录中的 `[合并转发]` 链接，即可在独立的只读编辑器中舒适查阅完整对话与内嵌图片。

## ⚙️ 设置界面与个性化

点击左侧列表齿轮图标或运行 `QQ: 连接设置`，即可打开现代化的卡片式设置页面：

- **服务连接设置**：配置 OneBot WebSocket 连接地址、访问 Token，一键测试连通性并实时显示当前登录的 QQ 昵称与账号。
- **外观与高亮定制**：
  - 自由切换 8 种编程语言的代码高亮风格。
  - 自定义 `@我` 与 `回复我` 的强调颜色，内置动态色块实时预览调节效果。
- **消息通知控制**：支持设置系统弹窗范围（全部消息 / 仅提醒与回复 / 完全静默）。
- **附件缓存管理**：直观查看本地图片与文件缓存的磁盘占用，支持自定义清理周期或一键清空无用缓存。
- **导入现有配置**：支持从 tuiqq 等现有配置文件中一键导入连接参数。

## ❓ 常见问题 (FAQ)

### Q: 提示连接失败或左侧列表为空？
1. 请确认你的 OneBot 服务端（如 NapCat、Lagrange）已成功启动并已登录 QQ 账号。
2. 检查服务端网络配置中开启的是 **WebSocket 服务端（正向 WS）**，而非反向 WebSocket。
3. 检查 IP 地址和端口是否匹配（同机通常为 `ws://127.0.0.1:3001`），Token 是否填写一致。
4. 确认服务端的**消息上报格式**已设置为 **`array`（数组格式）**。
5. 可在 VS Code 底部面板的 **输出 → QQ** 查看详细的连接与调试日志。

### Q: 如何区分 WebUI 地址与 OneBot 地址？
以 NapCat 为例，WebUI（网页控制台）地址通常形如 `http://127.0.0.1:6099/webui`，而插件需要连接的是**正向 WebSocket 接口**（如 `ws://127.0.0.1:3001`），请注意不要将网页地址填入插件。

### Q: 输入感叹号 `!` 没有打开表情面板？
输入 `!` 或 `！` 时，编辑器会弹出 `!表情` 补全候选，按下 `Enter` 确认后即可打开表情面板。如果不想发表情，直接按 `Esc` 取消补全即可正常输入感叹号。你也可以直接输入 `/emoji` 打开面板。

### Q: 点击消息中的图片或链接没有反应？
VS Code 编辑器中的文本链接默认需要通过 **Ctrl + 单击**（macOS 为 **Cmd + 单击**）触发打开。

### Q: 发送大文件或视频失败？
文件传输能力依赖服务端的 API 支持（如 NapCat 的文件流上传接口）。若服务端不支持该扩展接口，建议通过 QQ 官方客户端传输超大文件。

npm run build

npm test
